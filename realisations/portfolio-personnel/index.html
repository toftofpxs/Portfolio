Portfolio personnel

HTML/CSS/JSNetlifyVitrineResponsive

Contexte détaillé

Objectif du portfolio

La création d'un portfolio professionnel était essentielle pour présenter mes réalisations dans le contexte du BTS SIO. L'objectif était de concevoir une vitrine moderne, responsive et facilement accessible qui mettrait en avant mon parcours, mes compétences et mes projets réalisés durant la formation.

Résultats obtenus

Apports concrets

Le portfolio a été conçu et déployé avec succès sur Netlify, offrant une présentation claire de mon profil professionnel. Le site est entièrement responsive, optimisé pour mobile et desktop, avec une navigation intuitive et une mise en avant efficace des réalisations et compétences.

Architecture du site

Structure multi-pages avec sections dédiées à chaque domaine (parcours, compétences, projets, veille).

Stratégie responsive

Adaptation fluide sur trois points de rupture (mobile, tablette, desktop) pour une expérience optimale.

Extrait de code 01

Navigation responsive

Le menu mobile se replie automatiquement pour faciliter la navigation sur petit écran.

@media (max-width: 768px) {
  .nav-links {
    display: none;
  }
  .nav-burger {
    display: block;
  }
}

Extrait de code 02

Grille de projets

La grille s'adapte pour afficher les projets en colonnes multiples ou simples selon l'espace disponible.

.projects-stack {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 2rem;
}

Extrait de code 03

Optimisation de performance

Les images sont chargées de manière progressive pour améliorer le temps de chargement initial.

img {
  loading: lazy;
  decoding: async;
}

Vue d'ensemble

Page d'accueil du portfolio avec présentation et appel à l'action vers les réalisations.

Capture mobile

Affichage optimisé sur mobile avec menu repliable et sections adaptées.

Résultats et bilan

Bilan du portfolio

Ce projet m'a permis de maîtriser la création d'un site complet de présentation professionnelle, du design à la publication sur Netlify. J'ai appris à concevoir des interfaces responsive, à optimiser les performances et à maintenir un portfolio vivant avec des mises à jour continues.

Sprints du projet

Organisation Scrum Agile

Sprint 1: cadrage du besoin, decoupage des user stories, priorisation du backlog et definition des criteres d'acceptation.

Sprint 2: developpement des fonctionnalites principales, points quotidiens (daily), integration continue et corrections des blocages.

Sprint 3: tests, stabilisation, revue de sprint avec demonstration, puis retrospective et plan d'amelioration pour la suite.

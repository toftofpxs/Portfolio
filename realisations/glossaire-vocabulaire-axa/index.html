Glossaire Vocabulaire AXA

EntrepriseAXAGlossaireDocumentation

Contexte detaille

Besoin de standardisation

Au sein de l'equipe chez AXA, de nombreux acronymes, termes metiers et expressions techniques etaient utilises de facon heterogene selon les interlocuteurs. L'objectif etait de recenser l'ensemble de ce vocabulaire, de le structurer par domaine et de le rendre consultable facilement pour faciliter l'integration et la communication interne.

Resultats obtenus

Un referentiel vivant

Le glossaire regroupe les termes techniques, metiers et organisationnels classes par categorie. Chaque entree inclut une definition claire, des exemples d'usage et des liens vers les ressources associees. L'outil est maintenu et enrichi au fil des nouveaux besoins identifies en equipe.

Architecture MVC

Les pages de consultation sont servies par un controleur qui interroge la base du glossaire.

Extrait de code 01

Recherche d'un terme

La fonction de recherche filtre les termes en temps reel sur le label et la definition.

function searchTerms(query, terms) {
  const q = query.toLowerCase();
  return terms.filter((term) =>
    term.label.toLowerCase().includes(q) ||
    term.definition.toLowerCase().includes(q)
  );
}

Extrait de code 02

Rendu d'une entree

Chaque entree est generee dynamiquement depuis les donnees du glossaire.

function renderTerm(term) {
  return `
    <dt class="term-label">${term.label}</dt>
    <dd class="term-def">${term.definition}</dd>
    <dd class="term-example">${term.example}</dd>
  `;
}

Extrait de code 03

Filtrage par categorie

Le filtre par domaine permet d'isoler les termes metiers, techniques ou organisationnels.

function filterByCategory(terms, categoryId) {
  if (!categoryId) return terms;
  return terms.filter(
    (term) => term.categoryId === categoryId
  );
}

Resultats et bilan

Bilan du projet

Ce projet m'a permis de travailler la structuration de contenu et la gestion d'une base documentaire maintenable. La rigueur de definition des termes et la collaboration avec les membres de l'equipe m'ont appris a allier technique et communication metier dans un contexte professionnel exigeant.

Methode de travail

Organisation Scrum Agile

Sprint 1 : recensement des besoins, identification des domaines metiers, structuration du schema de donnees et mise en place de l'environnement de contribution.

Sprint 2 : saisie et validation des termes metiers avec l'equipe, developpement de l'interface de consultation et mise en ligne d'une premiere version utilisable.

Sprint 3 : enrichissement continu du glossaire, correction des definitions validees en equipe, ajout du filtrage par domaine et stabilisation de l'outil.

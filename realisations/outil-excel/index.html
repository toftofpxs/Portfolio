Contexte détaillé

Objectif de l'outil

En alternance 2ème année, l'équipe devait traiter régulièrement de gros fichiers Excel volumineux avec des opérations répétitives de tri et filtrage. L'objectif était de développer un outil web capable d'automatiser ces tâches et de réduire drastiquement le temps de traitement manuel des données.

Résultats obtenus

Apports concrets

L'outil a été déployé et permet aux utilisateurs de charger des fichiers Excel directement dans le navigateur, d'appliquer des filtres et des tris complexes en quelques secondes, et d'exporter le résultat. Cela a réduit le temps de traitement de plusieurs heures à quelques minutes.

Flux de traitement

Le fichier est chargé, parsé côté client, filtré puis exporté sans communication serveur.

Architecture MVC

L'interface permet à l'utilisateur de configurer les filtres qui sont appliqués au modèle de données.

Extrait de code 01

Chargement du fichier Excel

SheetJS permet de parser le fichier directement en JavaScript sans passer par le serveur.

function handleFileUpload(event) {
  const file = event.target.files[0];
  const reader = new FileReader();
  reader.onload = (e) => {
    const workbook = XLSX.read(e.target.result, {type: 'array'});
    const data = XLSX.utils.sheet_to_json(workbook.Sheets[workbook.SheetNames[0]]);
    displayTable(data);
  };
  reader.readAsArrayBuffer(file);
}

Extrait de code 02

Filtrage en temps réel

Les filtres s'appliquent instantanément sans délai de traitement serveur.

function applyFilters(data, filters) {
  return data.filter(row => {
    return filters.every(f => 
      row[f.column]?.toString().toLowerCase().includes(f.value.toLowerCase())
    );
  });
}

Extrait de code 03

Export du résultat

Le fichier filtré est exporté en Excel avec la même structure que l'original.

function exportToExcel(filteredData) {
  const ws = XLSX.utils.json_to_sheet(filteredData);
  const wb = XLSX.utils.book_new();
  XLSX.utils.book_append_sheet(wb, ws, "Données");
  XLSX.writeFile(wb, "resultat_filtré.xlsx");
}

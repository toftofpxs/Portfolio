Refonte de site

Responsive UX Vitrine

Contexte détaillé

Objectif du projet

La mission consistait à refondre un site vitrine pour clarifier l'offre de service, améliorer la lisibilité des contenus et faciliter la prise de contact. Le site d'origine manquait de hiérarchie visuelle, de cohérence mobile et d'appels à l'action visibles.

Approche

Choix de conception

J'ai réorganisé l'information autour d'un parcours simple: présentation, preuves de sérieux, services, avis et contact. La refonte s'est concentrée sur la vitesse de compréhension et le confort de lecture sur mobile.

Diagramme de classes

Le contenu est structuré par pages et sections, avec un formulaire de contact traité séparément.

Architecture MVC

La séparation template, contrôleur et contenu facilite les mises à jour sans casser la structure du site.

Extrait de code 01

Configuration des sections

Le contenu principal est piloté par une structure claire pour simplifier la maintenance.

const sections = [
  { id: "hero", title: "Accueil" },
  { id: "services", title: "Services" },
  { id: "contact", title: "Contact" }
];

Extrait de code 02

CTA prioritaire

Le bouton d'action reste visible et lisible pour orienter rapidement l'utilisateur vers la prise de contact.

const primaryCta = document.querySelector("[data-cta]");

primaryCta?.addEventListener("click", () => {
  window.location.href = "#contact";
});

Extrait de code 03

Adaptation responsive

Le layout bascule proprement sur mobile pour préserver l'ordre des informations essentielles.

@media (max-width: 768px) {
  .hero-layout {
    grid-template-columns: 1fr;
  }
}

Résultats et bilan

Bilan du projet

La refonte a renforcé ma capacité à transformer un besoin de communication en structure claire et actionnable. J'y ai travaillé la hiérarchie de contenu, la cohérence responsive et les choix UX orientés conversion.

Contexte detaille

Besoin documentaire

Le portail a ete pense pour centraliser des procedures techniques, des guides de resolution et des consignes de maintenance. Le but etait de limiter la dispersion d'information et de rendre la connaissance accessible rapidement aux equipes.

Resultats obtenus

Apports pour l'equipe

La documentation est structuree par categories, avec un format homogene et des chemins de navigation simples. Cela facilite l'onboarding, reduit le temps de recherche et ameliore la qualite des interventions repetitives.

Diagramme de classes

Le portail relie categories, articles et revisions pour conserver l'historique documentaire.

Architecture MVC

Les pages affichent des contenus documentaires servis par une couche de controle simple.

Extrait de code 01

Indexation des articles

Cette fonction cree un index de recherche simple pour accelerer la consultation des pages.

const searchIndex = articles.map((article) => ({
  id: article.id,
  title: article.title.toLowerCase(),
  tokens: article.content.toLowerCase().split(/\s+/)
}));

Extrait de code 02

Rendu markdown

Le contenu des procedures est converti en HTML pour une lecture uniforme sur le portail.

import { marked } from "marked";

function renderArticle(markdown) {
  return marked.parse(markdown);
}

Historique de revision

Resultats et bilan

Bilan du portail

Le portail documentaire a clarifie la circulation de l'information technique dans l'equipe. Cette realisation m'a permis de travailler la structuration de contenu, la recherche d'information et la maintenance d'une base documentaire exploitable au quotidien.

Sprints du projet

Organisation Scrum Agile

Sprint 1: cadrage du besoin, decoupage des user stories, priorisation du backlog et definition des criteres d'acceptation.

Sprint 2: developpement des fonctionnalites principales, points quotidiens (daily), integration continue et corrections des blocages.

Sprint 3: tests, stabilisation, revue de sprint avec demonstration, puis retrospective et plan d'amelioration pour la suite.
